# MoonTouchstone 开发范围与提交检查点

按原五项目 BENCHMARK-STANDARD.md 执行。当前版本 0.2.0 是本地开发版本，未发布。

1. 网络模型与复数矩阵：行优先、零起点；频率 Hz、阻抗 ohm；SI 制 Y/Z/H/G。
2. Touchstone 1.0/1.1 文本，RI/MA/DB、四种频率单位，正确处理旧格式非 S 参数归一化。
3. Touchstone 2.0/2.1、逐端口实参考阻抗、full/upper/lower、二端口顺序、多行记录。
4. 噪声参数与 mixed-mode order 元数据保存；不把 mixed-mode 数据假装 single-ended 进行分析。
5. S/Y/Z/H/G 适用转换；奇异或数值不可靠的转换明确拒绝。
6. 阻抗重归一化、端口选择和区间内复平面插值。
7. 二端口级联和左右夹具去嵌入。
8. 互易、无源诊断，群时延、回波/插入损耗、驻波比。
9. 真实文件 CLI、拒绝覆盖、明确非零错误退出码和可运行例子。
10. scikit-rf/NumPy 独立对照、适当规模测量、CI 配置、源码绑定验证记录。

限制：1–32 端口，有限内存文件，不支持复参考阻抗、稀疏/二进制扩展，不承诺 full RF simulator。运算中不能保存或正确变换的噪声/混合模元数据必须明确拒绝或由调用者显式丢弃。不同表示可能存在数学奇点，不能以加任意微扰伪造精确转换。

## 注释与提交规则

2026-09-27 增补：`Network::check_ripple` 计算采样通带峰峰插损及原始极值点，至少两个样本、有限/无限/未定义语义、覆盖不足三态判定；用厂家公开 S2P 和独立 NumPy/scikit-rf 验证。任务与数据许可边界见 [PUBLIC-SAMPLE](PUBLIC-SAMPLE.md)。这是基于实际数据表任务增加的聚合约束，不扩大为器件认证。

原冻结范围之外的本地工作流增强：`Network::check_bands` 以五种标量指标执行多频段采样点限值检查，提供原始定位、无穷/未定义语义、汇总和受限 CSV 明细。细节见 [BANDS](BANDS.md)。这不取代原十项范围，也不扩大为连续频带认证、任意失配功率分析或完整 RF 仿真。

每个检查点按实际独立功能提交，不以行数或提交数替代工作量。注释明确公式方向、量纲、限制与来源。每次提交正文记录 Why、Checked、Limits；没有验证的检查点不能勾选完成。
